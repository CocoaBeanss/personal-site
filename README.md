# personal-site

Résumé site for Maxime Defossez. Plain HTML and CSS, no build step.

- `index.html` — all the content. Replace anything in `[square brackets]`.
- `styles.css` — the look (light and dark themes, plus a print layout for saving as PDF).

Open `index.html` in a browser to preview. To publish with GitHub Pages:
Settings → Pages → deploy from the branch that holds these files, folder `/`.
